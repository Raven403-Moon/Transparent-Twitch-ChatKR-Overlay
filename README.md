# Transparent-Twitch-ChatKR-Overlay
[![GitHub](https://img.shields.io/github/license/moonkyu12/Transparent-Twitch-ChatKR-Overlay)](https://raw.githubusercontent.com/moonkyu12/Transparent-Twitch-ChatKR-Overlay/master/LICENSE)
[![GitHub release (with filter)](https://img.shields.io/github/v/release/moonkyu12/Transparent-Twitch-ChatKR-Overlay)](https://github.com/moonkyu12/Transparent-Twitch-ChatKR-Overlay/releases)

창 모드 또는 테두리 없는 창 모드 게임 위에 Twitch 채팅을 표시하는 Windows용 .NET 애플리케이션입니다. 주로 게임 플레이 중 채팅을 확인해야 하는 단일 모니터 스트리머를 위해 사용됩니다.

본 프로젝트는 baffler의 [Transparent Twitch Chat Overlay](https://github.com/baffler/Transparent-Twitch-Chat-Overlay)를 기반으로 한국어 번역 및 수정을 진행한 파생 저작물입니다. GNU General Public License v3.0 (GPL-3.0)에 따라 자유 소프트웨어로 배포됩니다.

**위키를 확인해 보세요:** [링크 참조](https://github.com/baffler/Transparent-Twitch-Chat-Overlay/wiki). 다양한 유형의 채팅 추가, Twitch 및 YouTube 채팅 통합, 구독/팔로워/포인트 보상 표시 방법, 시청자 수 표시 방법 등 필요한 모든 위젯 설정에 대한 설명이 안내되어 있습니다.

* 이슈 등록: https://github.com/moonkyu12/Transparent-Twitch-ChatKR-Overlay/issues
* 기능 요청 및 질문: https://github.com/moonkyu12/Transparent-Twitch-ChatKR-Overlay/discussions

## 설치 및 사용법
* 최신 릴리스 다운로드: https://github.com/moonkyu12/Transparent-Twitch-ChatKR-Overlay/releases
* 설치 관리자(Installer)를 다운로드하면 프로그램 설치가 간편해지며 필수 종속 요소([WebView2 런타임](https://go.microsoft.com/fwlink/p/?LinkId=2124703))가 자동으로 설치됩니다.
* Windows Defender SmartScreen으로 인해 "Windows의 PC 보호" 메시지가 나타날 수 있습니다. "추가 정보"를 클릭한 후 "실행"을 클릭하세요. 최초 실행 시에만 이 작업이 필요합니다.
* 프로그램을 처음 실행한 후 설정에서 Twitch 채널을 지정해야 합니다. 좌측 상단의 버튼을 클릭하여 설정을 열거나, 상단의 검은색 테두리를 마우스 우클릭하거나, 작업 표시줄 트레이 아이콘을 마우스 우클릭할 수 있습니다.
* 상단의 얇은 검은색 테두리를 클릭하고 드래그하여 창을 이동할 수 있으며, 우측 하단의 크기 조절 그립을 드래그하여 크기를 조절할 수 있습니다.
* 테두리를 숨기려면 우측 상단의 [o] 버튼을 클릭하거나 작업 표시줄 트레이 아이콘을 우클릭하세요.
